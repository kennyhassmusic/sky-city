# Sky City

Kenny Hass's Unreal Engine 5.8 project: a futuristic city that fuses **Austin and Chicago**, built for
**driving and flying the Skyster Roadster** from his browser game Skyster
(https://kennyhassmusic.github.io/skyster/, source github.com/kennyhassmusic/skyster).

Contributors: read CONTRIBUTING.md first. The city's buildings come from Epic's free City Sample, which is
not in this repo (docs/SETUP_CITY_SAMPLE.md). No real brand names or logos in anything you add: the game's
car brand is the invented **Volta Motors**.

Rules and setup for AI assistants working on a contribution: @AGENTS.md

## The city (brief, to grow with Kenny)

- Chicago's bones: the Loop's dense grid of towers, the river with its bridges, the elevated L,
  the lakefront and Lake Shore Drive, Navy Pier, Grant Park.
- Austin's character: the Colorado River / Lady Bird Lake, Congress Avenue up to the Capitol,
  South Congress, the hills and live oaks, the newer glass towers, live-music streets.
- Futuristic: sky lanes and landing pads at several heights, towers you can drive up (the
  Roadster wall-rides), boost pads, fast chargers, light and holograms, electric cars and helper robots.
- Built for the car: wide, flowing streets and ramps, long straights for top speed, loops that
  launch into the air, rooftop routes, open air space between towers for flying.

## The Roadster (from Skyster)

- Player car model: Kenny's GLB, `SourceArt/roadster_master.glb` (50 MB, plain glTF with PNG
  textures: import this one; Skyster's slimmed copy uses meshopt + webp, which Unreal may not read).
  Named nodes for animation: Wheel_*_Steer / Wheel_RL / Wheel_RR, HeadlightPanel_L/R_Hinge (panels
  drop DOWN into their pockets to show the lamps), Spoiler_Lift / Spoiler_Hinge, FrontWing_Hinge,
  Fan_*, Booster_*. GLB frame: +Y up, +Z forward, +X = the car's left, metres; Unreal's glTF import
  converts to centimetres, +Z up, +X forward.
- Wheelbase 2.825 m, length about 4.7 m, roof 1.24 m. Physics in Skyster are Rocket League's,
  scaled to that wheelbase (230 mph top speed, 3 s boost tank, jumps, flips, wall riding,
  flight mode on LB). Fuel add-ons stretch flight time: nitrogen x2, combustion x3, rocket x4.

## Working with the editor over MCP

- The editor runs Epic's built-in MCP server (plugins `ModelContextProtocol`, `AllToolsets`,
  `ToolsetRegistry`) at `http://127.0.0.1:8000/mcp`; Claude's connector is named `unreal-mcp`.
  Open the project with `./launch.sh` (starts the server); for good, turn on
  Editor Preferences > Model Context Protocol > Auto Start Server.
- It is tool-search mode: `list_toolsets`, `describe_toolset`, `call_tool`. The tool's inputs go in
  `arguments` (not `parameters`). **One call at a time**: the server runs on the editor's game thread.
- Look before and after changes (viewport capture), keep the level saved, and prefer procedural
  building (PCG, splines, data-driven Blueprints) over hand-placing hundreds of actors.
- The plugin is experimental: if a tool is missing after enabling something, run the console
  command `ModelContextProtocol.RefreshTools`, or restart the editor.
- Editor logs on macOS live in `~/Library/Logs/Unreal Engine/SkyCityEditor/SkyCity.log`, not the
  project's Saved/Logs.

## Git LFS

- LFS files download from Cloudflare R2 through the Worker in `tools/lfs-r2-worker` (set in `.lfsconfig`); uploads go
  to GitHub through `lfs.pushurl` in the clone's own git config. In a fresh clone that pushes art, set it first
  (docs/MAINTAINER_SETUP.md, "Git LFS downloads from Cloudflare R2"). The `lfs-mirror` Action copies new LFS files
  to R2 after each push to main.

## Scripts

- Most of the world is generated by the Python scripts in `Scripts/` (editor Python console, Blender, or
  plain python3). They find the project folder themselves; set `SKYCITY_ROOT` to override. Their inputs
  are the OpenStreetMap extracts in `SourceArt/osm` and the generated JSON in the tracked parts of `Saved/`.
